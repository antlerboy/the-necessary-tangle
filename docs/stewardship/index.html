Maintaining the record

Corrections belong in the maintained atlas data or the release script that generates it. The reading pages, interactive atlas, and downloads are built from that data.

A release needs its source and review records, existing interactive links, and calendar subscriptions to remain intact. Record failed source checks and unresolved questions.

Responsibilities

  • Curator: decides what enters a release and remains responsible for its wording.
  • Contributors: identify the statement, propose a change, and give sources and locators where available.
  • Maintainers: build the pages and downloads, check links and accessibility, and preserve existing interactive routes.
  • Automated checks: test structure, consistency, links, and page behaviour.

Reuse

Original atlas text and data use CC BY-SA 4.0. Entry downloads contain entries, connections, source metadata, and passage locators. Keep attribution, scope, release, and review status with reused records. Source documents and evidence excerpts aren’t included. Linked works keep their own terms.
