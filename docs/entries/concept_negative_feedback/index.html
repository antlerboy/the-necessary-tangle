Negative feedback

A feedback relation in which the returned effect opposes a change or deviation in the relevant variable; the reference condition, loop gain, delay and mechanism must be specified.

Summary

Negative feedback returns an effect that opposes deviation or change. It is the basis of many stabilising mechanisms, but its result depends on gain, delay, measurement and the dynamics of the system being regulated.

Implications for practice

The phrase is often used as if negative means criticism or undesirable effects. In technical use it describes loop sign. Poorly timed or overpowered negative feedback can oscillate or destabilise rather than calmly restore a set point.

Key distinctions

  • negative sign vs negative judgement
  • balancing tendency vs guaranteed stability
  • explicit set point vs implicit viable range
  • error correction vs suppression of useful variation

Historical development

  • Black 1934: stabilised amplifier design
  • Rosenblueth, Wiener and Bigelow 1943: goal-directed behaviour and negative feedback
  • Wiener 1948: general cybernetic synthesis

Ideas it depends on

  • feedback loop
  • deviation or change to be opposed
  • return path
  • adequate timing and response

Further developments

  • feedback control
  • homeostatic mechanisms
  • balancing loops in system dynamics
  • error-correcting organisational routines

Connections to practice

  • check whether the correction arrives too late
  • ask what useful variation is being damped
  • avoid assuming tighter control is better control
  • identify who sets the reference condition

Common confusions

  • negative feedback is criticism
  • it always produces stability
  • it requires a humanly stated target
  • it is always ethically desirable

Further checks

  • Bode and Nyquist stability analysis
  • physiological mechanisms beyond simple loops
