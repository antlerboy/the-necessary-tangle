Summary

Ivo Velitchkov works across systems and cybernetics, organisation, enterprise architecture and knowledge representation. His contributions are especially useful where viable organisation, dynamic balance, surplus variety and explicit semantics meet.

Implications for practice

Velitchkov's work joins management cybernetics, viable organisation, dynamic balance, surplus variety, enterprise architecture and explicit semantic representation. It provides substantive routes between organisational practice and knowledge-graph design.

Key distinctions
