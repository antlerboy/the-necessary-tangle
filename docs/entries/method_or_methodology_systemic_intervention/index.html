Systemic Intervention

A systemic methodology that begins with critical reflection on boundaries and values, then draws on methodological pluralism to support responsible action in complex situations.

Summary

Systemic Intervention refuses the idea that the problem and method are already given. It asks how boundaries and values create marginalisation, then selects and combines methods in relation to the situation.

Implications for practice

Method choice is itself an intervention. Boundary critique helps practitioners see whose concerns, knowledge and consequences are being made central or peripheral.

Key distinctions

  • methodology vs toolkit
  • boundary critique vs stakeholder listing
  • pluralism vs method shopping
  • intervention vs detached analysis

Connections to practice

  • start with boundary questions
  • surface marginalised concerns
  • choose methods for complementary purposes
  • record consequences and revise the intervention

Common confusions

  • use several methods and call it systemic
  • boundary critique is only scoping
  • pluralism means all methods fit
  • the practitioner is outside the intervention
