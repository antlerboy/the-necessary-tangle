How a collection becomes a field — or pretends to

Bibliography, selection, canon and connection

A route through the difference between inventorying a collection and understanding a field.

This is an editorial reading route. Claims about influence or dependence need the evidence recorded against the relevant connection.

Follow this journey interactively

  1. Start with the editorial object

    A collection is a selected argument about what counts as foundational. Inventorying it makes the selection inspectable; it does not ratify it.

    Read Foundational Papers in Complexity Science

  2. Name the wider field

    The field contains institutions, rival programmes, mathematical formalisms, empirical domains and histories that no one collection can exhaust.

    Read Complexity

  3. Follow a recurring concept

    A shared word may connect papers, but its formal meaning and explanatory role can differ sharply across domains.

    Read Emergence

  4. Test the apparent family resemblance

    Similar language can hide different mechanisms, levels and normative assumptions. A useful map records those differences.

    Read Self-organisation

  5. Move from bibliography to argument

    A developed entry needs definitions, disputes, evidence and uses — not merely an appearance in a table of contents.
