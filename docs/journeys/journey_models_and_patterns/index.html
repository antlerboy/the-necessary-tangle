What is producing the pattern?

Four models, four different explanatory jobs

Compare spatial instability, temporal sensitivity, movement feedback, and repeated-game cooperation by asking what each model actually assumes and explains. This is an editorial sequence, not a historical lineage or a common organisational law.

This is an editorial reading route. Claims about influence or dependence need the evidence recorded against the relevant connection.

Follow this journey interactively

  1. What amplifies a spatial difference?

    Distinguish a growing spatial mode from the eventual nonlinear form. Specify a local process, exchange mechanism, geometry, and possible falsifying observation before transferring the model.

    Read The Chemical Basis of Morphogenesis

  2. How long is a detailed projection useful?

    Separate deterministic rules from state precision and a decision-relevant prediction horizon. The paper's truncated convection example provides no organisational horizon.

    Read Deterministic Nonperiodic Flow

  3. Which local rules produce this distribution?

    Distinguish preference, feasible movement, reference neighbourhood, and aggregate outcome. Keep institutional causes and unequal power available; visual resemblance does not identify a cause.

    Read Dynamic Models of Segregation

  4. What sustains a reciprocal response?

    Name the payoffs, probability of another encounter, recognition, and interaction ecology. Test tournament success, stability, and initial viability separately rather than call one strategy universally best.

    Read The Evolution of Cooperation
