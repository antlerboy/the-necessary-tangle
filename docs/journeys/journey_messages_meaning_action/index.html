The message arrived. What happened?

Transmission, interpretation, and the capacity to act

A practical route through communication questions, feedback, and response capacity. The links between the steps are editorial questions, not assertions of historical influence.

This is an editorial reading route. Claims about influence or dependence need the evidence recorded against the relevant connection.

Follow this journey interactively

  1. Ask which problem you have

    Did the message arrive accurately? Was it understood as intended? Did it change conduct? Compare the three questions in a real exchange.

    Read Technical, semantic, and effectiveness questions

  2. Name the distinction

    What did the recipient learn that they did not know before? State the meaning of information being used here.

    Read Information

  3. Follow the return

    What happens to information about the result? Who receives it, and which action can it change?

    Read Feedback

  4. Check the response repertoire

    Information alone does not supply time, authority, or possible responses. Examine what the recipient is able to do.

    Read Requisite variety

  5. Include the interpreter

    Ask another person to describe the same exchange. Differences in the accounts may expose assumptions the first description hid.

    Read Observer
