David Ing: systems in plural

Move through David Ing’s own systems work and the documentary practices that make systems lineages inspectable.

This is an editorial reading route. Claims about influence or dependence need the evidence recorded against the relevant connection.

Follow this journey interactively

  1. Start with the practitioner-researcher

    Ing contributes his own systems work while also preserving unusually rich trails through systems communities and teaching.

    Read David Ing

  2. Use the public archive

    Coevolving records publications, courses, talks and collaborations over time.

    Read Coevolving Innovations

  3. Move into service systems

    Service systems thinking treats value and service as relational and contextual rather than as isolated outputs.

    Read Service systems thinking

  4. See a method translated between domains

    The pattern-manual work changes the pattern form rather than simply importing a built-environment template.

    Read Pattern Manual for Service Systems Thinking

  5. Shift from systems change to systems changes

    Systems Changes Learning attends to temporality, rhythm, contexture and propensity in living systems.

    Read Systems Changes

  6. Keep learning and action together

    The approach is organised as ongoing learning rather than a fixed-stage change programme.

    Read Systems Changes Learning

  7. Document lineages without inventing genealogies

    Events, citations and institutions can establish contact and context; influence needs stronger evidence.

    Read Systems lineage documentation

  8. Compare another people-centred map

    Ramage and Shipp provide a different route through thinkers and traditions, useful for triangulating lineages.

    Read Systems Thinkers
