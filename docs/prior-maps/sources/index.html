Referenced maps and histories

Earlier maps help you see how people have organised the field: as a history, a family tree, a classification or a route into practice. Those forms answer different questions. This directory gives attribution, a reference route and the limits of what has been checked.

Use it alongside the interactive map collection and the atlas’s mapping principles. A source map’s lines aren’t automatically accepted as atlas relationships.
