What a line really means

A link is a keyword-labelled citation signal in this particular corpus. Records whose titles matched the source term contained cited-reference strings matching the target term, at least five times across at least three distinct citing records.

That is weaker and more awkward than “work on X cites work on Y”, because the matching is lexical and concepts can be broad, overlapping or ambiguous. It does not establish influence, agreement, derivation, importance or a clean citation between two settled literatures.

What is and is not reproducible

The build and validation code are included. The run reported 85,832 source documents and 13,792,287 cited-reference rows. The licensed source corpus and its shrink step are not public, so this release cannot independently reproduce the figures. They remain Nigel’s reported aggregate result, now labelled accordingly.

The public dataset keeps aggregate weights, distinct-citing-record counts, concentration flags, years and exemplar DOI handles. It publishes zero raw Scopus reference strings, abstracts, affiliations, keywords or EIDs. A private Claude artefact URL from the fork has also been removed.
