Black box: what does the record establish?

Atlas · Profile · Update

A black-box investigation chooses ways to act on a system and ways to observe what happens. A record can show patterns in the tested inputs and outputs without revealing a unique account of what connects them inside. It can also leave some behaviours untested.

An example

Imagine two stipulated devices. Each accepts inputs 0, 1, or 2. In the trials so far, both have returned 0 for input 0 and 1 for input 1. Neither has yet been tested with input 2. One candidate rule returns its input for all three values; another returns 0 for input 2 while matching the first rule on 0 and 1.

Both candidate rules fit the recorded trials. They make different predictions for input 2. A suitable test could distinguish these rules if input 2 can be applied and the relevant conditions are repeatable. Until then the record does not establish which prediction is right. A real system might fit neither rule, or its response might depend on history or conditions not recorded.

This example concerns uncertainty about untried behaviour. A different question is whether knowing all behaviour at the chosen inputs and outputs identifies the physical mechanism. Ashby gives examples of different internal arrangements with the same specified behaviour. Agreement at a chosen interface does not establish that the physical arrangements are identical, nor that they agree under other observations or interventions. The example above does not prove or assume that its two rules have any particular internal mechanism.

What to record

Name the input that was actually applied, the output observed, the sequence and timing, and the conditions in which each result was obtained. Record which inputs and states were not tried, which could no longer be reached, and where repeat trials differed. A response can depend on an earlier state; a list of input-output pairs without their sequence may conceal that dependence. Ask what further observation would distinguish the competing predictions, and whether the test can be performed without changing the relevant conditions.

Ashby also distinguishes a simplified description that remains well-defined within its chosen distinctions from an incomplete list of cases. A partial description can be useful without being a complete account of the whole. But not every way of grouping states preserves a determinate description.

The two-rule example is original and stipulated; it is not an experiment or a claim about an organisation. Ashby's discussion is in An Introduction to Cybernetics, chapter 6, especially §§6/2–6/7 and 6/13. Grammar of Systems' named First and Second Black Box Principles are separate source-owned statements and are not equated with this account.
