How collection and calendar updates work

Sources use iCalendar feeds, structured event data, or source-specific parsers. Dated events are deduplicated, with source links retained. Calendar IDs stay stable when details change. Cancelled events retain their cancellation status. If a source fails, its previous events remain visible with a warning.

Only the details an organiser publishes are used. Missing times, time zones, and locations are labelled. Check the organiser’s page before booking or travelling.

New sources discovered through the monitored organisations are recorded for review before they are included. The source register and collection history are public in GitHub.
