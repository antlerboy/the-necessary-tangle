# Contributing to The Necessary Tangle

Corrections, challenges and additions are part of the project. They do not alter the atlas automatically.

## Choose the right route

Use a GitHub Issue to:

- correct an entry;
- challenge a connection or claim;
- suggest a better source;
- propose a missing idea, person, publication, institution or method;
- report a problem with the website.

Use GitHub Discussions for:

- open questions;
- interpretation;
- wider disagreement;
- exploratory connections that are not yet ready to become proposed records.

## What makes a useful contribution

State:

1. the entry or connection concerned;
2. the smallest precise change or challenge you are proposing;
3. why it matters;
4. the source;
5. the exact page, section, timestamp, archive reference or other locator where possible.

A public URL is preferred. Where no open copy exists, give a complete bibliographic or archive citation and mark it ‘No public link’.

## Editorial outcomes

A proposal may be:

- accepted;
- accepted with revised wording or scope;
- kept visible as disputed;
- held for more evidence;
- declined with a reason.

Disagreement is not removed merely because an editor makes a current judgement.

## Do not submit

Do not publish:

- private email;
- internal company or client documents;
- personal data that is not already legitimately public;
- credentials, tokens or private URLs;
- large copyrighted extracts.

Summarise the evidential point and cite the source instead.

## Pull requests

Small code and documentation pull requests are welcome. Changes to atlas data should normally begin as an Issue so that the claim, scope and evidence can be reviewed before data files are edited.

By contributing code, you agree that it may be distributed under the software licence in `LICENSE-SOFTWARE.md`. No public licence is yet granted for contributed atlas text or data beyond the permissions required to review and publish the accepted contribution in The Necessary Tangle; this will be clarified before a broader content licence is adopted.
