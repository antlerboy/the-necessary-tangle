# Participation and access

The Necessary Tangle is open to use, criticism and proposals. Repository access is granted by agreement, not by submitting a form.

## Project roles

### Reader

Anyone may use, question and discuss the atlas. No application is required.

### Proposer

Anyone with a GitHub account may submit a correction, challenge, source, missing entry or usability problem through an Issue. A proposal does not change the atlas automatically.

### Research contributor

A contributor works through a fork and pull request. This is the normal route for a bounded corpus, lineage, data or documentation contribution. Direct write access is not required.

### Reviewer

A reviewer examines evidence, wording, boundary choices, uncertainty and competing accounts. The role advises the curator; it does not carry an automatic merge right.

### Maintainer

A maintainer has trusted, limited responsibility for code, data or release maintenance. Direct repository access is exceptional and can be withdrawn.

### Curator

[Benjamin P Taylor](https://www.antlerboy.com/) is accountable for membership decisions, current wording, merges and public releases.

## What GitHub can enforce here

The repository currently belongs to a personal GitHub account. In that setting GitHub distinguishes the owner from collaborators, but does not provide the finer Read, Triage, Write, Maintain and Admin roles available to organisation repositories.

The project roles above are therefore enforced through contribution routes and curator decisions. Proposers use Issues. Research contributors use forks and pull requests. Reviewer status is a project role. Collaborator access is reserved for trusted maintenance.

Moving the repository to a GitHub organisation remains an option when the real workload justifies enforceable granular roles and a wider governance arrangement.

## Agent-assisted participation

An LLM or other automated tool acts under a named human sponsor. It does not hold membership in its own right. The sponsor must disclose the tool, check the sources and diff, and remain responsible for the submission. See [AGENTS.md](../AGENTS.md).

## Applying

The public Membership page prepares a GitHub application. It asks for the proposed role, contribution, evidence checks, public examples and any planned agent assistance. The form grants no access. The curator may accept, narrow, defer or decline the request.
