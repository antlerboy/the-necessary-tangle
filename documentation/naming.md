# Naming rule

The public project name is **The Necessary Tangle**.

Use it exactly in:

- the site title and headings;
- repository documentation;
- release names;
- social descriptions;
- citations;
- public conversation.

Do not shorten the public name. The word ‘necessary’ carries part of the argument: the atlas examines necessary conceptual antecedents, necessary scope extensions and the evidence necessary to sustain a connection.

The internal data namespace `scc_bok` may remain in historical or machine-facing records. It is not a public alternative name.
