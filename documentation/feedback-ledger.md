This ledger records what happened to the substantive requests in the original running-feedback thread. It is not a victory list. ‘Implemented’ means that a visible mechanism or bounded first pass exists in the current release. It does not mean the underlying field has been covered.

The running thread remains public at issue #2. A discreet dot at the bottom right of the website opens it. New notes can be rough. This document is the more disciplined account of what those notes have caused.

## A note on completion

A feedback item is not complete because a checkbox exists. It is complete only at the level stated. ‘Registered corpus’, ‘inventory’, ‘developed profile’, ‘typed connection’ and ‘gold-standard lineage’ are different achievements. The ledger keeps those differences visible so that interface polish cannot quietly convert intention into evidence.
