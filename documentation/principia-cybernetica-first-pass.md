# Principia Cybernetica: first pass

Principia Cybernetica deserves treatment as both content and predecessor.

It developed an explicit evolutionary-cybernetic philosophy and, from the early 1990s, represented it as a connected public hypertext. Its own server page records a July 1993 web registration, more than 2,000 linked nodes, papers and books, and an unfinished structure containing explicitly empty or incomplete nodes.

Typed, sourced connections record project membership, collaboration in developing the web, the project's self-identification with evolutionary cybernetics, Turchin's formulation of metasystem transition, the project's development of that theory, the web's semantic-network form, and links to emergence and self-organisation.

## Why it matters to this project

Principia Cybernetica confronted several of the same design problems:

- how to represent a broad body of knowledge without forcing a single reading order;
- how to connect concepts through stated relations;
- how to allow distributed contribution;
- how to integrate breadth and depth;
- how to expose incompleteness;
- how a knowledge network might adapt and reorganise.

It also carries a strong philosophical programme. Its architecture and its substantive worldview must not be collapsed into one judgement. A useful comparator can be technically prescient, intellectually partial and historically uneven at the same time.

## Limits of this pass

This release samples a small set of project-authored pages. It does not claim to have reviewed the full site.

The next pass should:

- inventory in-scope nodes and their authorship/date metadata;
- distinguish complete, incomplete and empty nodes;
- map the Web Dictionary's component glossaries and named authors;
- trace external claims to original sources;
- compare relation types and navigation with The Necessary Tangle;
- analyse the annotation and participation model;
- identify how the site's own categories shape its apparent worldview;
- record what has been superseded, migrated or left historically frozen.
