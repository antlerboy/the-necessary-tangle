# Security and sensitive information

The Necessary Tangle is a public repository and public website. Do not submit credentials, private documents, client information, personal data, internal URLs or confidential extracts through public issues or pull requests.

For an ordinary content correction, use the structured contribution route on the website.

For a security or privacy concern, use the repository's Security area and private vulnerability reporting where available. If that route is unavailable, contact the curator through https://www.antlerboy.com/ without reproducing the sensitive material in a public thread.

## Supported version

The current `main` branch and the live GitHub Pages release are supported. Earlier public releases are retained as history but are not separately patched.

## Response

The curator will assess whether the report requires a content correction, credential rotation, history rewrite, takedown request or other action. Public disclosure may be delayed until the immediate risk has been contained.

There is no bug-bounty programme.
